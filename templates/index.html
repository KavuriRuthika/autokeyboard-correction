Key Engineering Insights for Demonstration:

  • LSTM Generalization: The embedding and hidden recurrence allow the neural network to generalize across unseen word sequences with lower test perplexity.
  • N-Gram Speed: The 4-gram hash lookup achieves sub-millisecond predictions, making it an ultra-lightweight candidate for embedded or mobile keyboards.
  • Bayesian Autocorrect: Combining QWERTY physical key adjacency with language priors enables accurate single-keystroke typo recovery (e.g. teh -> the, smarr -> smart).
